# 永無島的黃昏：影子、時鐘與不沉之船

永無島三部曲第三部（最終章）｜國小國語文第三學習階段（高年級）遊戲式線上測驗。

## 執行
直接用瀏覽器開啟 `index.html`，或在此資料夾執行 `py -m http.server 8000` 後開啟 http://localhost:8000 。

## 結構
- `index.html`：畫面結構（封面、選夥伴、劇情、答題、失敗、證書）
- `css/style.css`：黃昏暮光紫紅 × 暗金 × 日系 RPG 風格（沿用三部曲設計規範）
- `js/game.js`：四關完整劇情、夥伴台詞、抽題（指標保證機制）、拖曳互動、本地調試快捷鍵 F2/F3/F4
- `js/bank_mc.js`：154 題選擇題（解析自《第三學習階段_國語文選擇題題庫》《高年級階段_成語與四字語詞題庫》與劇情試煉題）
- `js/bank_drag.js`：34 題拖曳題（多音字詞配對、形近字詞配對、句子重組、四字語詞題組、短長文閱讀理解）
